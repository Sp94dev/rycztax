# Feature: Auth

**Cel:** Umożliwienie użytkownikowi rejestracje oraz logowanie do systemu.

## Kryteria Akceptacji

* [X] Użytkownik może stworzyć konto podając email i hasło
* [X] Użytkownik może się zalogować
* [X] Niezalogowany użytkownik jest przenoszony do ekranu logowania, nie ma dostępu do prywatnej części aplikacji
* [X] Użytkownik po zalogowaniu jest przenoszony do widoku plików
* [X] Użytkownik po wylogowaniu jest przenoszony do ekranu logowania


## Zależności

* Dane pobierane z Firebase Auth
