# Feature: Auth

**Goal:** To enable user registration and login to the system.

## Acceptance Criteria

* [X] User can create an account by providing an email and password
* [X] User can log in
* [X] An unauthenticated user is redirected to the login screen and does not have access to the private part of the application
* [X] After logging in, the user is redirected to the files view
* [X] After logging out, the user is redirected to the login screen


## Dependencies

* Data fetched from Firebase Auth

## Sub-features / Detailed stories

## Ideas and extensions

* User panel where they can enter their company data
* Login with Google
* Login with Apple
* Login with Facebook
